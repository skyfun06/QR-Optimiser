Kit vendeur à imprimer — dépose les PDF ici
============================================

Place les deux fichiers PDF dans CE dossier (public/kit-vendeur/),
avec EXACTEMENT ces noms :

  1. chevalet.pdf         → bouton "Chevalet comptoir"
  2. cartes-visite.pdf    → bouton "Cartes de visite"

C'est tout. Aucun code à modifier.

Dès qu'un fichier est présent, son bouton de téléchargement s'active
automatiquement dans l'espace vendeur (onglet "Tableau de bord",
zone "Mes outils"). Tant qu'un fichier est absent, le bouton reste
désactivé avec la mention "Bientôt disponible".

Note : après avoir déposé un fichier, il faut redéployer l'application
(les fichiers de public/ sont servis en statique). En local, un simple
rechargement suffit après avoir relancé le serveur de dev.
